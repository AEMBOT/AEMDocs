# Learning
## Prerequisites
This documentation assumes a basic familiarity with Java programming. In particular, you'll need to understand
the following concepts:
<!-- FIXME: More complete set of concepts -->
- Basic understanding of Java (variables, objects, methods, polymorphism, inheritance, etc.)
- Understanding of interfaces & abstract classes
- Knowledge of generic [objects](https://docs.oracle.com/javase/tutorial/java/generics/types.html) and [methods](https://docs.oracle.com/javase/tutorial/java/generics/methods.html)

If you're completely new to Java, and especially if you're completely new to programming, I'd suggest consulting your mentors regarding the best way for you to learn. Here are a few resources that you may find helpful:
- [Oracle's Learning the Java Language Trail](https://docs.oracle.com/javase/tutorial/java/index.html): Oracle's official guide to learning Java. It might not be very accessible, but may be useful if you're familiar with other languages.
- [W3Schools' Java Tutorial](https://www.w3schools.com/java/default.asp): W3Schools' tutorial is somewhat shallow, but I'd say it's very accessible.
