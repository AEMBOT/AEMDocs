:::warning
    The AEMLib library was rapidly developed somewhat in parallel with this robot while under a lot of crunch.
    As a result, the 2026 robot code is unpolished in many places, and uses a rather outdated version of AEMLib.
:::

Our 2026 robot, Anubis, was made for the [2026 FRC Season: REBUILT](https://en.wikipedia.org/wiki/Rebuilt_(FIRST)). It shot foam balls called "fuel" into a large bin-esque field element called the hub. Game pieces were collected via an over-the-bumper intake, which also served as an indexer, pushing game pieces into a hooded & turreted flywheel shooter.
